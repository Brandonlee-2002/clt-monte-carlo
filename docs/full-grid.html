Explore Every Sample Size

Choose an integer n, choose the graph, and inspect the evidence immediately

This interactive explorer is the detailed companion to the report’s increment-based summary graphs. The slider evaluates every integer n from 2 through 500 using the same four normality criteria and the same 10,000-repetition simulation design.

2 How to interpret the explorer

  • Sampling distribution shows the simulated distribution of the 10,000 sample means at the selected n.
  • Normal Q-Q plot compares standardized simulated quantiles with theoretical normal quantiles. Points closer to the dashed diagonal indicate closer agreement.
  • Diagnostic thresholds shows the four numerical criteria as criterion-load bars. A bar ending at or before the orange boundary passes that criterion.
  • All populations at this n compares the pass/fail screen across every population at the selected integer.

The status badge refers to the exact selected integer. The “first stable pass” line refers to the first n followed by two additional consecutive passing integers.

Note

The interactive page uses one reproducible simulation path per population and cumulative sums to make every integer n available efficiently. Because the primary candidate-grid experiments reset the seed separately for each candidate, small Monte Carlo differences between the two views are expected. The diagnostic criteria and stable-pass rule are unchanged.

3 Reproduce the interactive data

From the repository root:

Rscript R/run_full_grid.R
Rscript R/run_interactive_data.R
quarto render full-grid.qmd --no-clean --cache-refresh

The compact visual data are saved to results/tables/full_grid_visuals.json and copied to docs/assets/full-grid-visuals.json for the published site. The interactive JavaScript is maintained in assets/full-grid-explorer.js.
